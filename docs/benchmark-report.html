Optimization Phases

Phase 0 — Baseline

All hot-path ops on boundedElastic (40-thread cap). Synchronized rate limiter. Duplicate limiter releases. Per-chunk usage scanning.

Phase 1 — Stream Hot Path Cleanup +238%

boundedElastic → parallel() for in-memory backend. Conditional [DONE] sentinel. Simplified usage guard (contains("usage") only). Removed 4 duplicate concurrentRequestLimiter.release() calls.

Phase 2 — Resilience4j + Netty Tuning +10%

decorateStreamFlux(): single CB+Bulkhead check at subscribe, no per-signal operators, no retry on Flux. Reverted Netty loop threads to CPU core count.

Phase 3 — Correctness Fixes

Fixed FORCED_OPEN CB state bypass for streams. Tightened [DONE] detection to data: [DONE]. Verified no double-release remains.
